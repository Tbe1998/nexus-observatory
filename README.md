# NEXUS · 实时运算中枢 v1.0.2

把本机真实的运行状态变成一套可长时间观看的计算观测装置：左侧神经网络与巨型计算圆环，
中部五路粒子分发，右侧五个接收模块，下方六个真实活动看板，全部由本机采样驱动。

- 平台：Windows 10/11（浏览器需支持 WebGL2：Edge / Chrome 均可）
- 形态：本地 Python 采样服务（仅绑定 127.0.0.1）+ 浏览器图形界面
- 依赖：Python 3.9+、psutil（其余全部前端原生实现，无 CDN、无外部字体/图片）

## 一、快速开始

### Windows

1. 解压整个文件夹（路径里最好不要有中文以外的特殊符号）。
2. 双击 **`启动 NEXUS.bat`**。
   - 自动找 Python 3；没有会给出中文提示和下载地址。
   - 缺 `psutil` 会自动从清华镜像安装（失败会提示手动命令）。
   - 采样服务隐藏窗口启动，然后自动打开默认浏览器。
   - 已经在运行时不会重复起第二个采样器，直接打开页面。
3. 结束监控：点页面右下角 **「结束监控」**，或双击 **`停止监控.bat`**。

### 命令行（Windows / Linux / macOS）

```bash
pip install -r requirements.txt
python sampler.py                 # 默认 127.0.0.1:8768 并自动开浏览器
python sampler.py --port 8770 --no-browser
python sampler.py --once          # 只打印一次采样（排查用）
./start.sh                        # Linux/macOS 快捷入口
```

> 换端口时页面地址要跟着换，例如 `http://127.0.0.1:8770/`。

## 三、真实数据与口径

默认每秒采样一次，动画独立连续渲染；前端用采样序号去重，同一帧采样只生成一次任务。

| 渠道 | 读数定义 | 单位 |
|---|---|---|
| 处理器 | 整体 CPU 忙碌时间比例（psutil `cpu_percent`），并读取每逻辑核心负载、进程 CPU 时间增量 | % |
| 内存 | 物理内存已用比例（`total - available`） | % |
| 显卡 | **最繁忙引擎的利用率**（不是各引擎相加）。Windows 读 `GPU Engine(*)\Utilization Percentage`，NVIDIA 走 `nvidia-smi`，Linux AMD 读 `gpu_busy_percent` | % |
| 下载 | 活动物理网卡的实际接收字节速率与包数增量 | KiB/s、MiB/s |
| 上传 | 活动物理网卡的实际发送字节速率与包数增量 | KiB/s、MiB/s |

边界处理：

- 第一次采样没有差分基线 → 网络显示 `--` 与「不可用」，不补 0。
- 进程退出、PID 复用：按 PID + CPU 时间增量重新建立基线。
- 网卡切换、累计计数器重置（增量为负）→ 该次按 0 处理并重新取基线。
- 受保护进程读不到 → 跳过，不猜测。
- GPU 计数器不可用 → 显示 `--` 与原因，绝不编造百分比。
- 采样器离线或数据超过 3.2 秒未更新 → 顶部与状态栏转为「采样离线」，不拿陈旧值冒充实时。

> 磁盘、温度、风扇等未采集；不读取文件内容、命令行、窗口标题、浏览历史、网络包内容。

## 四、指标 → 动效映射

```
百分比指标： speed = 0.035 + (使用比例 ^ 1.15) × 1.35
网络指标：   speed = 0.025 + clamp[ ln(1 + 字节速率/8192) / ln(1 + 10485760/8192) ] × 1.65
```

- 五路**独立**映射：处理器只影响处理器通道，其余同理；下载与上传互不影响。
- 速度变化按指数平滑（约 0.3 秒时间常数），不会每秒跳速。
- 低负载渠道保留可辨认的连续粒子链（提高亮度/宽度补偿），但不夸大速度。
- 「极速分发」在**独立映射结果**上叠加约 2.8 倍视觉倍率，不改变读数、门槛或过载判断。
- 环境装饰动效（圆环背景缓存闪烁、稀疏码条）与实测任务在亮度、位置和节奏上区分开。

### 过载门槛（严格大于才触发）

| 渠道 | 默认门槛 |
|---|---|
| 处理器 | 45 % |
| 内存 | 60 % |
| 显卡 | 50 % |
| 下载 | 512 KiB/s |
| 上传 | 128 KiB/s |

- 实际指标 **> 门槛**：进入持续过载视觉状态；**≤ 门槛**：立即恢复。
- 各渠道独立判断，不会一路过载带动五路。
- 「预览」按钮持续 2 秒，明确标注「预览」，不改门槛、不改读数、不记为故障事件。
- 持续过载与「抵达反馈」分开：抵达反馈是能量真正到达接收端时的短促冲击。

## 五、五种引擎

| 引擎 | 中央形态 | 自动配色 | 过载接收效果 |
|---|---|---|---|
| 环状流场 | 连续粒子带，五路并行外送 | 保留当前颜色 | 短促冲击 |
| 黑洞引擎 | 暗核 + 倾斜吸积盘 + 引力透镜环，每 1.5 s 一道整体引力波（单道 2.7 s，最多同时两道），粒子被吸引弯曲后外送 | 星云紫 | 短促震动 + 裂纹 + 少量碎片 |
| 聚变引擎 | 程序化太阳（体积感、颗粒、活跃区、日冕），空间折射流输出 | 香槟金 | 热蚀：迎光边缘炽热 + 金白高光 + 热纹 |
| 三体引擎 | 三体引力数值模拟（软化引力、固定步长、柔和边界），带历史轨迹与弹射 | 冷白银 | 引力剪切：三层错位 + 残影后快速重组 |
| 推理引擎 | 六层网络 5/11/15/15/11/5 = 62 节点，层间传导 0.66–0.87 s，并发上限 144 组 | 深海蓝 | 算力洪峰：三路并行候选 + 缓存格 + 暖珊瑚高光，抵达后寄存条冲刷 |

- 进入某个引擎会自动应用它的配色；进入后仍可手动改色；再点该引擎按钮会重新应用自动色。
- 「环状流场」不强制改色，保留你当前选择。
- 太阳固定金橙/橙红，不随主题配色变化；换色改的是图形自身颜色，不是整页滤镜。

## 六、交互

- 鼠标进入神经元区域：附近节点局部偏移、连线提亮，移开自然恢复。
- 点击神经元：局部波纹 + 邻近节点依次激活 + 向圆环注入一次视觉能量；**不改变读数、不触发全渠道过载**。
- 点击右侧接收模块：聚焦该渠道（其余变暗），再次点击恢复。
- 全屏：浏览器原生全屏，保留顶部栏、看板、状态栏；Esc 退出。
- 参数面板：动效倍率、粒子数量（2,000–20,000）、光感强度、圆环节拍、神经/计算光效开关、过载特效开关、五路门槛与预览、鼠标交互开关、自动聚焦、恢复默认。
- 设置（引擎、配色、门槛、粒子数、开关、极速分发）保存在浏览器 localStorage，刷新后保留。

### 性能说明（重要）

构建环境**没有 GPU**，只能用 SwiftShader 软件渲染，实测每帧 JS+GL 提交成本：

| 引擎 | 软件渲染每帧耗时 | 折算上限 |
|---|---|---|
| 环状流场 | 26.7 ms | ≈ 37 FPS |
| 黑洞引擎 | 40.9 ms | ≈ 24 FPS |
| 三体引擎 | 73.0 ms | ≈ 13 FPS |
| 聚变引擎 | 91.3 ms | ≈ 11 FPS |
| 推理引擎 | 0.5 ms（无粒子流） | 不受限 |

这些是**最差情况**（纯 CPU 光栅化，软件渲染会把每一像素都算一遍）。
在有独显/核显的 Windows 机器上，同样的绘制批次由 GPU 承担，帧率会显著提高；
页面状态栏会实时显示真实 FPS，请以目标机器读数为准。粒子数、光感强度都可在参数面板下调。

## 九、已知限制

1. **没有做成 Windows 单文件 exe**：PyInstaller 无法在 Linux 上交叉打包，本包要求目标机安装 Python 3.9+。
   若需要免安装版，请在 Windows 上执行 `pyinstaller -F -w --add-data "web;web" sampler.py`（未在本轮验证）。
2. **GPU 读数依赖系统计数器**：部分老驱动/虚拟机没有 `GPU Engine` 计数器，会显示 `--`；NVIDIA 走 `nvidia-smi`。
3. 太阳与黑洞是**程序化着色器**生成的，不是太阳观测影像，也不代表实时天文画面；三体是视觉模拟，不是天文预测。
4. 推理引擎借用大模型计算的视觉语言，不读取任何模型的注意力权重或内部状态。
5. 本机测试环境无 GPU、无外网流量，截图中的显卡为 `--`、下载/上传接近 0 属正常。
6. 多显示器、超高 DPI（>160%）下的极端缩放未做专项测试；渲染分辨率已限制在 1.6 倍 DPR 以内。

## 十一、更新记录

**v1.0.2（2026-11-11）**
- 修复「隔一段时间提示采样服务未连接」：Windows 读 GPU 计数器要拉 PowerShell，原来在采样线程里同步跑，
  单次可能阻塞数秒，快照间隔超过前端阈值就被判成离线。现在 GPU 读取在独立后台线程（3 秒刷新），
  采样循环稳定在 1 秒，慢采样只记日志不拖累数据。
- 前端轮询改为带 4 秒超时的链式请求；偶发一次超时不提示，连续两次才提示；
  数据到得慢显示「数据延迟」，真断开才显示「未连接」，恢复后自动清除。
- 修掉同一个采样序号重复到达时离线横幅不被清除的逻辑漏洞。


**v1.0.1（2026-11-11）**
- 修复 Windows 下双击启动后「什么都没发生」：`pythonw.exe` 的 `sys.stdout` 是 `None`，
  服务里的提示输出会让进程在第一行就抛 `AttributeError` 退出，端口根本没起来。
  现在所有输出走 `log()`（写 `nexus.log` 并安全回显），并加了启动异常弹窗。
- `启动 NEXUS.bat` 重写：跳过 Microsoft Store 的 python 占位程序、常见安装路径兜底、
  启动后做最长 12 秒健康检查，失败时停在窗口里打印并打开 `nexus.log`。
- 新增 `诊断 NEXUS.bat`：一键输出解释器、psutil、端口、文件完整性、前台采样测试，写入 `诊断结果.txt`。

## 十二、故障排查

| 现象 | 处理 |
|---|---|
| 双击后没反应 | 先双击 `诊断 NEXUS.bat`，把 `诊断结果.txt` 发出来；v1.0.1 起启动失败会停在窗口里并显示 nexus.log |
| 提示找不到 Python | 安装 Python 3.9+，勾选 Add to PATH |
| 端口被占用 | 启动器会自动顺延端口；或 `python sampler.py --port 8770` |
| 页面显示「采样服务未连接」 | 采样服务没起来：看是否有 pythonw 进程；重新运行启动器 |
| 页面黑屏且提示不支持 WebGL2 | 换 Edge/Chrome 最新版，或在设置里开启硬件加速 |
| 显卡显示 `--` | 系统没有可读的 GPU 计数器（虚拟机/老驱动常见），属正常降级 |
| 想彻底停掉 | 双击 `停止监控.bat`，它会先请求退出再兜底清理进程 |
