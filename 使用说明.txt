NEXUS · 实时运算中枢 —— 使用说明
==================================================

【这是什么】
把本机真实的 CPU / 内存 / 显卡 / 下载 / 上传读数，变成一套实时可视化观测装置：
左边神经网络和巨型计算圆环，中间五种引擎，右边五个接收模块，下面是六个真实活动看板。
所有数字都来自你这台电脑的实时采样，不是演示数据。

【怎么启动】
1. 整个文件夹解压到任意位置（不要只把 bat 单独拷出去）。
2. 双击「启动 NEXUS.bat」。
   · 第一次会检查 Python 与 psutil，缺失会自动安装（需要联网）。
   · 采样服务在后台隐藏运行，随后自动打开浏览器。
   · 已经在运行时不会重复启动，只会再打开一次页面。
3. 想全屏展示：点右上角「全屏」，按 Esc 退出。

【怎么停止】
· 页面右下角「结束监控」；或
· 双击「停止监控.bat」（会先请求退出，再兜底清理残留进程）。
停止后浏览器页面可以关掉。

【主界面怎么看】
顶部：连接状态、采样时间、采样序号、极速分发、全屏、四种配色、参数。
中间：左侧巨环与神经球；右侧从上到下是 01 处理器 02 内存 03 显卡 04 下载 05 上传。
底部：六个看板（处理器/内存/显卡 第一行，下载/上传/系统采样 第二行），每个都能点「详情」。
状态栏：主机、采样状态、粒子数、FPS、渲染方式、运行时间、结束监控。

【五种引擎】按钮在主视觉右上方
环状流场：五条粒子带持续外送，最接近“超算阵列”的常态。
黑洞引擎：暗核 + 倾斜吸积盘，每 1.5 秒一道引力波横扫五个接收端。
聚变引擎：程序化太阳，能量以空间折射的形式送出。
三体引擎：三个核心互绕、弹射，带历史轨迹。
推理引擎：六层网络高速并行传导，过载时出现“算力洪峰”。
切换引擎会自动换对应配色，之后仍可手动改色。

【读数说明】
· 显卡读的是“最繁忙的 GPU 引擎利用率”，不是各项相加。
· 网络单位一律 KiB/s、MiB/s（不是比特）。
· 显示“--”表示系统没提供这个指标，程序不会拿 0 或假数据顶替。
· 顶部出现“采样服务未连接”= 后台采样服务没起来或被关掉了，重新运行启动器即可。

【过载是什么意思】
过载只是“超过你设的视觉提示门槛”，不是硬件故障诊断。
默认门槛：处理器 45%、内存 60%、显卡 50%、下载 512 KiB/s、上传 128 KiB/s。
在「参数」里可以逐项改；每个渠道右边有「预览」，会演示 2 秒过载效果，但不改门槛、不改读数。

【隐私】
采样服务只监听 127.0.0.1，别人访问不到你的电脑。
只读系统统计与进程名/PID/线程数/资源占用；
不读文件内容、聊天记录、浏览历史、命令行、窗口标题、密码，也不把数据发到任何地方。

【常见问题】
· 双击没反应：在里面打开 PowerShell 运行 python sampler.py 看报错。
· 提示没有 Python：装 Python 3.9+，安装时勾选 Add Python to PATH。
· 画面很卡：参数里把粒子数量调小（例如 6000）、光感调低；或检查浏览器是否开了硬件加速。
· 显卡显示 --：虚拟机或老驱动没有 GPU 计数器，属正常降级。
